
 ## Expense Tracker (Frontend)

This directory contains the frontend implementation of the Expense Tracker application, built using core web technologies.

## Technologies Used
*   **HTML5:** Structured the user interface for tracking expenses.
*   **CSS3:** Provides a clean and responsive design.
*   **JavaScript:** Handles the dynamic logic for adding, deleting, and calculating expenses.

## Key Features
*   **Add Expenses:** Easily input transaction details (name and amount).
*   **Dynamic List:** View added expenses in a real-time list.
*   **Calculation:** Automatically calculates the total balance/expenses based on user input.

## How to Run
1. Clone this repository.
2. Navigate to the `html-css-js` folder.
3. Open `index.html` in any modern web browser to use the application.
